# slicer-profiles

Bambu Studio user presets for the Bambu Lab H3C: the owner's third-party filaments on the H3C Generic parents for each nozzle, and print styles (Strong, MM-Support) on the stock print presets, generated from a few tables so a change is made once and reaches every nozzle.
