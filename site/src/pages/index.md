# slicer-profiles

Print, filament and printer presets for the Bambu Lab P2S, the Snapmaker U1 and the Qidi X-Max 4 in OrcaSlicer, Bambu Studio, QIDI Studio and Snapmaker Orca, generated from one set of tables so every slicer gets the same settings.
